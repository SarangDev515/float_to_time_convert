Odoo 13 Addon

Float to Time Selector

Convert decimal-hour float fields into an easy, controlled AM/PM time selection experience.

What this module does

The float_to_time_convert widget changes the way a float field is edited. Instead of allowing users to type an uncertain numeric value, the field opens a circular time picker. Users choose the hour, minute, and period visually, while Odoo continues to store the value as a normal decimal-hour float.

How the time picker works

1

Open

Click the readonly-looking field while the form is in edit mode.

2

Choose hour

Select an hour from the light-blue circular hour clock.

3

Choose minute

The picker switches to a minute clock with exact 00–59 selection.

4

Choose period

Select AM or PM using the buttons below the clock.

5

Confirm

Click Use this time to save the selection.

Key features

Controlled data entry

Typing, pasting, and drag-and-drop input are blocked. Every value comes from the picker.

Two-step circular clock

The hour dial and minute dial are separated so the selection process stays clear.

Exact minute support

The minute clock supports every minute from 00 through 59, not only five-minute intervals.

Odoo-friendly storage

The selected value is saved as a decimal-hour float and remains compatible with existing models.

Form and list support

The widget can be used in regular form views and editable list views.

Readonly-safe display

Readonly views show the formatted time without opening the selector.

How values are stored

The user sees a familiar 12-hour time, while the database receives decimal hours.

02:30 PM → 14.5 14 hours and 30 minutes = 14.5 decimal hours
12:00 AM → 0.0 Midnight is stored as zero decimal hours
09:15 AM → 9.25 15 minutes is one quarter of an hour
11:45 PM → 23.75 23 hours and 45 minutes = 23.75 decimal hours

Usage in a view

Add the widget attribute to any Odoo float field.

<field name="your_float_field" widget="float_to_time_convert"/>

Example:

<form string="Work Schedule">
    <sheet>
        <group>
            <field name="start_time" widget="float_to_time_convert"/>
            <field name="end_time" widget="float_to_time_convert"/>
        </group>
    </sheet>
</form>

Installation and upgrade

The addon is designed for Odoo 13 and is already located in the configured extra addons directory.

Restart Odoo, update the Apps list, and install or upgrade Float to Time Selector. After upgrading, refresh the browser so Odoo rebuilds and serves the latest backend assets. The widget works in normal Odoo mode; debug assets are not required for daily use.

Compatibility notes

This module targets Odoo 13’s legacy JavaScript field widget system and depends on the Odoo web module. It does not create database models or alter existing float fields. Existing float values remain usable and are formatted as AM/PM when displayed through the widget.
